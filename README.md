Этот репозиторий содержит решение для тестового задания на стажировку infotecs (Разработчик C++), описанного в TASK.md. Используются C++17, GCC, CMake, STL и POSIX API без сторонних библиотек.

## Реализация требований

Библиотека поддерживает уровни важности сообщений, фильтрацию по минимальному уровню, изменение уровня по умолчанию и сохранение текста, уровня и времени сообщения.
Файловая и сетевая реализации используют общий интерфейс.
Тип библиотеки определяется опцией сборки `DBUILD_SHARED_LIBS` (По умолчанию - статическая).

Потокобезопасная передача данных в приложении реализована очередью, mutex и condition variable. Главный поток принимает ввод, отдельный поток выполняет запись. При завершении оставшиеся сообщения обрабатываются перед выходом.

Сетевая реализация корректно обрабатывает частичное получение данных и сообщения с переводами строк. Сборщик статистики выводит принятые сообщения, считает требуемую статистику и формирует отчёты после каждого N-го сообщения или по таймауту T, если данные изменились.

Параметры и входные данные проверяются. Ошибки файловых операций, создания потока, подключения, отправки, приёма и разбора сетевых данных возвращают диагностическое сообщение и корректно завершают выполнение. Для обработки ошибок в бизнес логике используются std::optional и пользовательские enum ошибок. Исключения в бизнес логике не используются.

## Сборка

Статическая библиотека:

```bash
cmake -S . -B build
cmake --build build
```

Динамическая библиотека:

```bash
cmake -S . -B build -DBUILD_SHARED_LIBS=ON
cmake --build build
```

Запуск тестов:

```bash
ctest --test-dir build
```

## Использование

Запись в файл:

```bash
./build/app/journal_cli <journal-file> <default-importance-level>
```

Запись в TCP-сокет:

```bash
./build/app/journal_cli --socket <host> <port> <default-importance-level>
```

Сборщик статистики:

```bash
./build/collector/journal_stats <address> <port> <N> <T-seconds>
```

Приложение последовательно запрашивает текст сообщения и его уровень. Пустой уровень означает использование значения по умолчанию. Завершение ввода выполняется через EOF (`Ctrl-D`).
